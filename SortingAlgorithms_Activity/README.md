**SORTING ALGORITHM ACTIVITY**



**1. Briefly explain what your Java program does.**



Kani nga java program kay nag gamit ug 3 ka sorting algorithms, kani ang bubble sort, selection sort, ug insertion sort. Kani dayun nag gamit ug array nga nay 10 unsorted numbers. Kada sorting algorithm kay nay iya-iya nga copy sa original 10 numbers para parihas ra sila ug numbers. Sa pag run dayun sa program ang una nga ipakita ang original 10 unsorted numbers ayha ang result sa tulo ka sorting algorithm.



**2. Explain how Bubble Sort works.**



Ang bubble sort kay gina compare niya and duha ka nag tapad. Kung mas dako ang naa sa left kaysa sa naa sa right mag swap dayun sila. Balik balik ra iyang pag compare from left to right hangtod ang mga number kay ma arrange na sugod pinaka gamay hangtod pinaka dako. Sa sigeg swap niya, ang mas dako nga number naabot na sa pinaka last dayun.



**3. Explain how Selection Sort works.**



Ang selection sort kay mangita sya sa pinaka gamay nga number sa wala pa na sort nga array. Tapos ug makakita na dayun niya, iya ning ibutang sa sakto nga position. Kada mahuman ug pasa mangita na sad dayun sa smallest number sa nabilin nga unsorted numbers, hangtod mahuman na dayun ug arrange.



**4. Explain how Insertion Sort works.**



Ang insertion sort kay mura kag ga arrange ug cards. Kwaon ang isa ka number tapos i sulod sa sakto nga position. Kung nay mas dako nga number, iya ning i move sa right aron makahatag ug space para sa sakto nga number na ibutang.



**5. Discuss the differences between the three sorting algorithms.**



Ang bubble sort kay gina swap tagsa tagsa ang ga abay hnagtod sa mahuman ug plastar tanan. Ang selection sort dayun kay mangita sa pinakagamay nga number tas ibutang dayun sa sakto nga position. Ang insertion sort dayun kay gakuha ug number tas ug diha na dayun iyang lugar gina insert na dayun ang number. Parihas silang tulo nga ga sort fron smallest to biggest pero lahi lahi ilang pamaagi sa pag arrange.





**REFLECTION QUESTIONS**



**1. How does each sorting algorithm arrange numbers? What makes their processes different?**



Ang bubble sort kay gina compare ang gatapad nga number ug gina swap dayun ug needed na i swap. Ang selection sort kay gapangita sa pinaka gamay nga number sa unsorted part tas gina butang sa sakto nga lugar. Ang insertion sort kay gakuha ug number ug ginabutang sa sakto nga lugar sa sorted part. Ang bubble sort kay ga focus lang sa swapping, and selection sort dayun sa pagpangita sa smallest number, ug ang insertion sort kay sa pag insert sa number.



**2. Among the three sorting algorithms, which one do you think is the easiest to understand and implement? Why?**



Para sa akoa kay ang bubble sort ang pinakasayon sabton ug i implement kay simple ra iyang process. I compare ra ang duha ka numbers nga nag abay ug i swap lang kung ang number sa left kay mas dako. 



**3. If the numbers are already sorted, which algorithm do you think would perform better? Explain your answer based on how the algorithms work.**



Para sa akoa kay ang insertion sort ang mas maayo kung sorted na daan ang numbers. Kung naa na sa sakto nga order ang array, dili na kaylangan i change ang number. Ipang check ra niya ang sunod nga number ug mopadayun.



**4. What will happen if you add more numbers to your array? How might this affect the performance of each algorithm?**



Kung mudaghan ang numbers sa array, mudaghan pud ang comparisons ug movements nga buhaton sa sorting. Mas dugay ang pag sort kung daghan na ang numbers. Ang bubble sort ug selection sort mahimong mas hinay tungod sa daghang comparisons. Ang insertion sort mahimong paspas kung hapit na ma sort ang numbers, pero mahimong hinay kung random ang arrangement.



**5. As a future programmer, why is it important to understand different sorting algorithms instead of using just one?**



Importanti nga makasabot ta ug lain lain nga sorting algorithms kay dili tanan parehas og performance sa kada situation. Naay algorithm nga mas angay kung gamay ra ang data, ug naa pud mga sorting methods nga mahimong hinay kung daghan kaayo ang numbers. Kung makasabot ta sa ilang differences, mas makapili ta og algorithm nga angay gamiton sa atong program.
